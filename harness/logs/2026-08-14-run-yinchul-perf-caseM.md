# Case M — Run 유인철 실사 공연 MV (이미지생성 퍼포머)

- **곡**: `music/tarao/Run 유인철.wav` (3:09 / 189.72s)
- **레퍼런스**: 공연자 멀티뷰 캐릭터 시트 `music/tarao/KakaoTalk_20260814_145543349.png` + Sparkle(etq-rWQOkz8) 어둠/스포트/숄더뷰 무드
- **산출물**: `design/idola/renders/run-yinchul-perf.mp4` (1920×1080, 189.72s, h264+aac, ~99MB)

## 접근
사용자 결정: **이미지생성 실사 퍼포머** + Sparkle 무드 유지. HDRP 저폴리 무대에 합성하면 오히려 실사 화질이 떨어지므로, 생성된 실사 프레임을 주인공으로 **시네마틱 켄번즈 편집**을 선택(실사 극대화).

## 파이프라인
1. **캐릭터 확보**: Gemini `edit` 모드에 레퍼런스 얼굴 시트를 입력해 얼굴 일관성 유지 → 14개 실사 공연 샷 생성(`image/gemini/2026-08-14-yinchul-*.png`).
   - 관객시점 클로즈업/정면/측면/기타연주/기타핸즈/와이드/숄더뷰(관객 폰라이트 리빌)/실루엣/눈물 익스트림클로즈/헤드다운/룩업/로우앵글/스테이지뷰
   - 파일럿 1장 검증 후 배치 생성(파일럿 게이트). 실패 1건(와이드, NoneType 세이프티) → 프롬프트 순화 재시도 성공.
2. **편집**(`scratchpad/build_run_mv.py`): 감정 아크 순서로 14세그먼트, 각 14.48s. 2560 프리스케일 후 zoompan 켄번즈(줌인/줌아웃/팬L/팬R), xfade 디졸브 1.0s(경계 offset i×13.48), 마지막 vignette+eq+noise 필름그레인. Run 오디오 먹싱(-shortest).
   - 총 길이 = 14×14.48 − 13×1.0 = 189.72s (곡과 정확히 일치).

## 결과
숄더뷰+관객 폰라이트 리빌, 눈물 클로즈업, 손 든 실루엣 클라이맥스 등 실사 공연 연출 완성. 얼굴 일관성 양호.

- HDRP 라이브 라이트-바다를 스크린블렌드 오버레이/전환 비트로 부분 합성(모션 강화)
