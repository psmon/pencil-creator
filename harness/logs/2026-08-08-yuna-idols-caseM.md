## 개선 패스 v2 — 단계적 재모델링 (사용자 피드백: 몸라인→손가락→헤어→얼굴모양)
스크립트: `infra/blender/yuna_body_v2.py` (재실행 가능). v1의 분리 프리미티브 바디를 폐기하고 스텝별로 재구축:

- **STEP 1 — 몸라인**: Skin 모디파이어 + Subsurf로 골격(척추/팔/다리 엣지)을 감싸 **연결된 여성 실루엣** 생성. 어깨→잘록한 허리→엉덩이 곡선. 가슴은 브랜치 버텍스가 크레이터를 만들어 → **살짝 파묻은 구体 2개**로 교체. 엉덩이는 백사이드 브랜치 버텍스로 볼륨, 발 추가로 접지. (정면/측면/34 다각 검증)
- **STEP 2 — 손가락**: 손목 연결 구体 + 손바닥(박스+Subsurf) + **손가락 4개(테이퍼) + 엄지**. 팔뚝-손 틈을 손목 구体로 브리지.
- **STEP 3 — 헤어**: 스캘프 캡(전면 절개로 얼굴 노출) + NURBS 스트랜드. 멤버별 스타일(long/pony/bun/halfup) + 컬러 파라미터화.
- **STEP 4 — 얼굴모양**: 스킨 척추에서 머리 제거 → **턱선(하관 테이퍼)+턱 전진**을 준 전용 헤드 메시에 실사 얼굴 텍스처 정면 투영(Generated X/Z, 헤드 단독 오브젝트라 bbox 정합). 매핑 크롭 튜닝으로 이목구비 정위치.
- **의상 재적합**: 새 바디 비율에 맞춰 상의(가슴 완전 커버)·스커트/반바지·신발/부츠 재구성.

**성과**: v1 마네킹/튜브 → v2 해부학적 여성 바디 + 손가락 + 실사 얼굴/헤어. 정면 앨범 컷에서 실사 아이돌 4인으로 식별.
**남은 한계**: 정면 투영 텍스처라 **3⁄4 각도에서 얼굴이 평면 마스크처럼** 보임(측면 왜곡). 완전 해결엔 스컬프팅+UV 언랩 또는 Hyper3D Rodin 포토리얼 메시 필요.

## 개선 패스 v5 — Hyper3D Rodin 이미지→3D 하이브리드 (전각도 해결)
트라이얼 키(hyper3d.ai, MAIN_SITE)로 이미지→3D 검증. **핵심 발견/해결**:
- **MCP 이미지 툴 버그**: `generate_hyper3d_model_via_images`가 "unsupported image format"으로 전량 실패(클린 이미지도). 원인=애드온이 이미지 바이트 대신 base64 문자열을 멀티파트로 전송 추정. → **Blender 안에서 Rodin API 직접 호출**(원본 바이트 multipart)로 우회 성공.
- **입력**: 턴어라운드 시트를 PIL로 정면/측면 전신 크롭(JPEG). 3⁄4 부분컷은 **유령 다리** 유발 → 정면+측면 2뷰만.
- **메시 모드**: "Raw"는 2.6만 셸로 파편화(씬 과부하→ .blend 재로드로 복구). → **"Quad"**로 깨끗한 단일 메시(17.8k정점).
- **오리엔테이션 함정**: glb는 쿼터니언 모드 → `rotation_euler` 무시됨. `rotation_mode='XYZ'` 후 X−90, 로컬 Y축(키) 기준 스케일.
- **Rodin 한계**: 몸·머리카락·의상은 **전각도로 충실**(후면 포니테일·백지퍼까지), 그러나 **얼굴은 이목구비 없는 흰 덩어리**(절차적과 정반대 트레이드오프).
- **하이브리드 해법**: Rodin 전각도 바디 + 앞머리 페이스 밴드(normal.y<−0.3, 상단 24cm) 분리 → **실사 얼굴 텍스처 정면 투영**. → 정면 또렷한 실사 얼굴 + 전각도 완전 3D 동시 달성(평면 마스크 해결).
- **파일럿(U) 산출**: `design/blend/yuna-idols-rodin.blend`, `design/idola/renders/yuna-U-hybrid.png`.
- **남은 작업**: Y(시트 _06)·A(_03)는 동일 파이프라인으로 배치 가능. N은 턴어라운드 없어 단체컷 크롭 필요. 각 멤버 트라이얼 생성 1회 소모.
