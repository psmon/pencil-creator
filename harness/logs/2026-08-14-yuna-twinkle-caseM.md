## 워크플로우

기존 YUNA Unity 파이프라인(4인 아이돌, 9무브 스킬풀, PerfClock 동기 디렉터 3종, PlayCapture)을
**새 곡 + 신규 별밤 무대**로 재구동. [[unity-yuna-pipeline]] · [[unity-mcp-setup]].

1. **곡 분석** — `analyze_song.py`(soundfile+numpy)로 138 BPM / 242.56s / 558비트 도출.
   구조: intro(0-3) verse(3-133) **climax1(133-160)** bridge(160-175) **climax2(175-230)** outro(230-243).
2. **안무 재타이밍** — `ChoreographyDirector.BuildSchedule()` 24세그먼트로 재작성.
   유니즌 5개(≈21%) + **양 고조에서 Y→U→N→A 스포트라이트 로테이션** + 곡선 아크 동선.
3. **별밤 "반짝임" 무대 신규** —
   - PIL로 `sky_twinkle.png`(딥 인디고 그라데이션 + 베이크드 스타필드 1400점+40 크로스플레어),
     `star_sprite.png`, `shooting_star.png` 생성.
   - `TwinkleStars.cs` — 260개 빌보드 별 쿼드를 반구 셸에 절차 배치, per-star 사인 위상으로
     반짝임 변조(PerfClock 구동 → 캡처에 결정적으로 baked).
   - `Sparkles` 파티클(부유 글린트, 가산 블렌드), 발광 문(스피어 재질), 딥나이트 플로어/그라운드.
   - 조명 = 쿨 문라이트(0.8,0.85,1.0) + 웜 핑크필 + 나이트 앰비언트.
   - URP Post 재구성: **Bloom(thr0.9/int1.1) + ColorAdjustments + Vignette + Tonemapping(Neutral)**.
4. **무대 디테일** — `MoonController` duration=242.5, 문 우→좌 아크 + **슈팅스타 크로싱(138-150s, climax1)**.
5. **카메라 재타이밍** — `CameraDirector.Build()` 23컷: 어프로치/돌리/스포트라이트 푸시인/
   **문·슈팅스타 히어로(140-150)**/유니즌 와이드 펀치/**문셋 아웃트로 크레인**.
6. **영상화** — PlayCapture(startFrame 오프셋 추가로 프리뷰 창 지원) 5822프레임 720p24 →
   ffmpeg로 원본 mp3 mux(결정적 캡처라 완벽 싱크).

## 확장 패스 2 — 사계절 전환 + 백댄서 12인 + 신규 안무 (동일 세션)

사용자 요청: ①무대를 봄→여름→가을→겨울→봄으로 전환(봄에 시작된 사랑이 겨울에 끝나 다음 봄을

- **신규 댄스 모션(Mixamo)**: 세션 만료 → 사용자가 Playwright 창에서 로그인. Playwright로
  6종 다운로드(FBX for Unity / Without Skin): **Rumba·Salsa·Shuffle·House·Locking·HipHop**.
  `.playwright-mcp/`에 저장 → `Assets/YUNA/Dances/`로 복사 → ModelImporter Humanoid+loopTime →
  `YunaMoves.controller`에 6 스테이트 추가(9→15). 다운로드 절차 = 결과카드 `.product` 클릭 →
  패널 Download → 모달 select(Format/Skin) evaluate 세팅 → 모달 Download(마지막 Download 버튼).
- **안무 재구성**: ChoreographyDirector 24세그를 신규 무브 위주로 재작성 + **계절 매핑**
  (봄=Rumba/Salsa 로맨틱, 여름=House/HipHop, 가을/climax1=Locking, 겨울/climax2=Shuffle 드라이빙,
  아웃트로=Rumba 희망). 유니즌 5개≈21% + 양 고조 Y→U→N→A 로테이션 유지.
- **사계절 전환**: `SeasonDirector.cs`(PerfClock 구동) — 키프레임 시간축
  {0,61,122,183,230,243}에서 스카이틴트/디렉셔널/필/앰비언트/플로어를 연속 lerp(smoothstep),
  4계절 파티클(**Petals→Motes→Leaves→Snow→Petals**)을 인접 계절 weight로 크로스페이드.
  계절별 파티클 스프라이트 PIL 생성(petal/leaf/snow, motes=star_sprite). 봄=로즈+벚꽃잎,
  여름=틸+금빛 모트, 가을=앰버+낙엽, 겨울=아이시블루+눈. 검증: 봄 로즈/벚꽃 vs 겨울 블루/눈 뚜렷.
- **백댄서 12인**: YUNA_Y 인스턴스 12개(2열×6, z=-3.3/-4.9 스태거) → 다크 실루엣 바디
  머티리얼 + 얼굴 데칼 비활성(백댄서 실루엣) → `YunaSolo9`(9무브 메들리) + `BackupDancer.cs`

## 함정/교훈 (신규)
- **Mixamo 캐릭터+애니 동시영입**: 캐릭터 클릭 후 URL goto 하면 캐릭터 리셋(Claire) → 인페이지 탭

  (다운로드 서버처리 중 navigate하면 취소됨). 실캐릭터는 With Skin FBX, 텍스처 추출+_BaseMap 수동할당.
- **스포트라이트 클로즈업은 전진 멤버가 짤리기 쉽다** → 풀백+와이드+GROUP 조준으로 전원 프레이밍.
- **무대 승강 = 관객 하강**: 댄서/카메라 y를 안 건드리고 관객을 피트(y-1.4)로 내리면 무대가
  높아 보임(카메라 재조정 불필요). 관객 zNear를 줄여 무대 앞 밀착.
- **악단 = 인스턴스 + 프로시저럴 악기 + 루프 무브**로 저비용 구현. 개성은 체형/코스튬색.
- **가산 빔은 밝은 배경에 묻힘**: 주간 씬에선 alpha 충분히(≥0.2) 줘야 보이고, 콘 방향(아래)
  회전 부호 주의. 야간에 가장 강렬.
- **무대+스크린 동시 = 정면 풀백 마스터**: 리버스(관객 전용)와 구분해 계절마다 1컷씩 배치.
- **백드롭에 순백 하드밴드 금지**: 소프트 그라데이션으로. 스크린 하부는 무대 뒤 눈높이라 눈에 띔.
- **주간 계절 실경화**: 밤 느낌은 조명(ambient/dirI)+돔색+별+달의 합이므로 전부 계절 구동해야 제거됨.
  LED 백드롭은 실경(하늘/바다/숲) 이미지로, 돔은 계절별 플랫 하늘색으로, 별은 겨울만.
- **밝은 돔 앞 다크 프레임 베젤은 배경을 어둡게** 만든다 → 주간 씬에선 베젤 제거하고 돔이 배경.
- **가수↔댄서 분리 = 리드/백업 무브 풀 분리**(리드 젠틀, 백업 풀댄스). 스포트 포메이션 유지 시
  featured가 앞으로 나와 솔로 노래 연출됨. 정면 댄서 카메라는 관객 피트 앞(z<zNear)에 둘 것.
- **LED 스크린이 어두운 밤하늘 이미지면 다크 서라운드에 묻힌다** → 백드롭을 전체적으로 밝게
  (top까지) + 그래픽 글로우 + brightness>1.5 + 서라운드를 더 어둡게 해 대비 확보. Unlit은 씬광
  무시라 자체발광 스크린처럼 보임(HDR 색으로 bloom 유도).
- **관중 배치는 카메라 방향 결정**: 정면(−Z) 샷엔 LED 백월이 배경, 관객(+Z)은 오버숄더(카메라를
  관객 뒤 z>zFar에 둬야 응원봉이 거대하게 안 잡힘)·리버스 크레인에서만 프레이밍.
- **동일평면 디스크 z-fighting**: 실린더 2개(Floor/FloorRim)를 같은 y로 내리면 캡 삼각팬이
  풍차형 z-fighting → 반드시 y로 분리.
- **관중은 +Z(관객석)** → 정면 카메라엔 안 보이고 관객석 대면 리버스 크레인에서만 확실히 잡힘.
  크라우드-포그라운드(관객석서 무대 보기)는 응원봉이 카메라 뒤/작게 잡혀 약함.
- **Mixamo 세션 24h 비활성 만료** → 사용자 로그인 필요(Adobe SSO). Playwright 창에서 사용자가
  직접 로그인. 다운로드는 `.playwright-mcp/claire-*.fbx`로 떨어짐.
- **Mixamo 캐릭터 라이브러리 = 리얼/몬스터 위주** → 큐트 아이돌과 스타일 충돌. 멤버 차별화는

- **관중은 +Z(관객석)에 배치** → 정면(−Z 방향) 카메라엔 안 보임(카메라 뒤). 관중은 리드 뒤에서
  +Z를 바라보는 관객석 대면 크레인 샷에서만 프레이밍 → 레퍼런스와 동일한 연출 문법.
