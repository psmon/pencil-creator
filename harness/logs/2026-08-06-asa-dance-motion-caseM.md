## Phase 1 — 레퍼런스 분석 (video-motion-analysis)
- overview(1s) → 강한 풀바디 프레이즈 2개 후보(11–16s, 24–30s) 식별
- fine(0.3s) 몽타주로 11–16s 채택: 크라우치→라이즈→오버헤드 리치→힙힌지→스윕업
- 신체비율 측정(13.7/14.9/15.2s): **인심 ≈ 0.53·H, 7.8헤드, 슬림 아이돌 실루엣** (오버사이즈 블레이저 + 허벅지부츠)

## Phase 2 — Blender 모델링 + 애니
- **리그**: 오브젝트 페어런팅 기반 FK (각 세그먼트 원점=근위 관절 → 관절 회전이 자식 전파). 아마추어 스키닝 회피(결정적·견고).
- **모델**: 측정 비율 그대로 미터 실치수. 의상 색분리(블레이저 회색 / 숏팬츠·부츠 블랙 / 스킨 / 밥 헤어)
- **애니**: 8개 풀바디 키프레임, Bezier 보간. FK 부호 규약 1패스에 정합 확인.
- **검증**: rest(workbench) → rest2(EEVEE 컬러) → 8프레임 체크몽타주 → 리파인 → 130프레임 시퀀스+스트립. 청크별 렌더 검증 수행.

## 개선 패스 v2 — 박자감 & 자연스러움 (사용자 피드백 반영)
- **문제**: 8키프레임 균등배치 → 느린 모핑, 히트/홀드/그루브 부재로 "박자감 없음·어색함"
- **정밀 재분석**: 11.4–15.8s @ 0.2s 몽타주로 히트 타이밍 추출 → **beat≈14프레임(~128BPM)**, accent-and-hold 구조 확인 (크라우치 홀드 / 힙힌지 홀드 / 스냅 히트)
- **절차적 리빌드** (매 프레임 베이크):
  - 9키포즈를 **박자 그리드**(f1,15,29,…113)에 락
  - **ease-out 스냅 + 홀드**: 세그먼트별 지수 EXP=[3,3,3,3.5,2,4,2.5,3] (큰 히트=4, 홀드=2)
  - **그루브 레이어**: 골반 상하 바운스(비트마다 dip) + 힙 스웨이(2비트 주기) + 골반 트위스트 + 머리 노드
  - **오버랩 액션(팔 드래그)**: 상완 2f / 전완 4f / 목 2f 지연 → 팔로우스루로 자연스러움 상승
- **산출**: `asa-dance-preview.mp4`(30fps) + `asa-dance-preview-slow.mp4`(15fps 박자 검수용). `.blend` 갱신(매프레임 베이크).
