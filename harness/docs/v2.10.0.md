## 신규 디자인 자산 공간

- `design/blend/` — 재활용 가능한 Blender 3D 마스터 자산. `.pen`과 동급의 관리 대상.
  - 첫 자산: `design/blend/acmer-dongtan.blend` (아파트 단지 + 한국형 20/30/40/80평 인테리어 4종)

## 실증 사례 (sample17)

1. 아파트 홍보영상(61s) → ffmpeg 프레임 30장 분석 → 단지 구조 수치화
2. Blender MCP로 타워 5동 + 포디움 + 조경 + 인테리어 4종 모델링 (EEVEE 검증 렌더 반복)
3. Three.js 단일 HTML 재구축 — 캔버스 파사드 텍스처, InstancedMesh, 컷어웨이(백페이스 컬링)
4. 카메라 연출 9종 (시네마틱 5 + 인테리어 투어 4: 어프로치→유리 관통→360° 룩어라운드)
5. GitHub Pages 퍼블리싱 (v1.2.2~)

## 커밋 규칙

- .blend 자산은 저장소 내부(design/blend/)에서만 관리 — 외부 경로 방치 금지
- 웹 재구축 시 블렌더 배치 수치를 그대로 이식 (웹에서 공간 재설계 금지)
