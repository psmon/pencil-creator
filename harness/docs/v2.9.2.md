# v2.9.2 — Pencil Ops 환경/운영 지식 추가

**변경 유형**: 패치 (knowledge 계층 신규 reference 문서 추가)
**날짜**: 2026-06-26

## 배경

펜슬 창이 멀티모니터 재배치 후 화면 밖으로 사라지는 문제가 반복 발생. 세션 중
실시간 진단으로 근본 원인(`config.json`의 `windowBounds`에 저장된 off-screen 좌표)을
찾아 복구에 성공함. 이 노하우를 일회성으로 흘리지 않고 하네스 지식으로 영속화.

## 변경 사항

### knowledge 계층
- `harness/knowledge/pencil-ops.md` 신규 — 펜슬 앱 운영/트러블슈팅 지식 문서.
  - **OPS1**: 멀티모니터 창 위치 복구
    - 근본 원인: `%APPDATA%\Pencil\config.json` → `windowBounds`에 종료 시 좌표 저장,
      화면 밖 상태로 닫으면 off-screen 좌표가 재저장되는 악순환. 레지스트리 아님.
    - 진단: `MainWindowHandle != 0` 필터로 실제 메인 창 식별 (헬퍼 프로세스 다수).
    - 즉시 복구: Win32 `SetWindowPos`/`ShowWindow`/`SetForegroundWindow` (한 PS 호출 내 Add-Type).
    - 영구 복구: 펜슬 종료 후 `windowBounds` 직접 편집 (실행 중 편집은 종료 시 덮어써짐).

### config
- `version`: 2.9.1 → 2.9.2
- `knowledge_docs`에 `pencil-ops` 등록 (`scope: environment`).

## 정합성
- 신규 knowledge는 평가 축/RPG 공식과 무관 (운영 지식). 기존 계층 참조 영향 없음.
- `scope: environment`로 표기하여 디자인 평가 knowledge(design-craft 등)와 구분.
