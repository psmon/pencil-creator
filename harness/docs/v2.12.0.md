## 세션 실증 누적 (YUNA Unity 파이프라인)

1. Unity MCP 셋업 (relay `--mcp --project-path`, 브리지 named-pipe/Editor PID)
2. 캐릭터 — Mixamo Claire 큐트 베이스, 텍스처 추출·URP·얼굴 알파클립
3. 개인기 9종 — Without-Skin 임포트 + Mecanim 자동 리타겟, 공통 스킬 풀
4. 4인 멤버 — 디퓨즈 HSV 리컬러(Y옐로/U라벤더/N차콜/A핑크)
5. 그룹 안무 — soundfile 곡 분석 + ChoreoDirector(유니즌 20% + 스포트라이트 로테이션 + 곡선 동선)
6. 무대 — 프로시저럴 아이스크림 무대 + MoonController(달 우→좌 + E.T. 자전거 패러디) + URP Post
7. 카메라 — CameraDirector 방송 컷(근접 프레이밍)
8. 영상 — **PlayCapture**(Time.captureFramerate + PerfClock) → ffmpeg mux

## 핵심 교훈 (영상 렌더 방식)

- ❌ 오프라인 `AnimationMode.SampleAnimationClip` + 오프스크린 렌더 = 스킨드메시 미갱신 → 캐릭터 정지
- ❌ Unity Recorder 5.1.2 = Unity 6.2와 비호환(GetInstanceID obsolete-error, 전체 컴파일 차단)
- ✅ **Play 모드 결정적 캡처**(PlayCapture) = 실제 Animator 모션 그대로 담김 → 유일한 신뢰 경로
