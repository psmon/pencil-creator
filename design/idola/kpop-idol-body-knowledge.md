> 목적: 한국 K-pop 여자 아이돌의 전형적 신체·얼굴 특징을 실측/연구 기반으로 파악하고,
> 이를 Blender 절차적 캐릭터(`infra/blender/yuna_body_v2.py`)의 수치 파라미터로 변환.

## 1. 신체 (Body) — 실측 vs 아이돌 스타일링

### 1-1. 실측 기준 (Size Korea 7차, 20대 여성)
| 항목 | 값 |
|---|---|
| 평균 신장 | 160~162 cm |
| 머리 길이 | 22.3 cm |
| **머리-신장 비율** | **7.2등신** (SD 0.31) |
| 가슴둘레 / 허리 / 엉덩이 | 83.6 / 69.3 / 92.8 cm |
| 허리:엉덩이 (WHR) | ≈ 0.72 |

### 1-2. 아이돌 스타일링 (미디어 이상치)
| 항목 | 값 | 비고 |
|---|---|---|
| 이상 신장 | 162~165 cm | 데뷔 평균 ~165 |
| 이상 체중 | 42~47 kg | "(키−120)=목표체중" 공식 통용 |
| 평균 BMI | **≈ 17.2 (저체중)** | 91% 아이돌이 BMI<18.5 |
| 체중 분포 | 83.5%가 40~49kg | — |
| 허리 | 17~24 inch (극세) | WHR ≈ 0.65~0.68 (실측보다 잘록) |
| 목표 룩 | **8등신(1:8)** | 실측 7.2보다 과장 — **작은 머리 + 긴 다리**로 착시 |

### 1-3. 아이돌 실루엣 3대 요소
1. **작은 머리 (소두)** — 몸 대비 머리가 작을수록 8등신 착시. 모델링에서 머리 축소가 핵심.
2. **긴 다리 (하체 비율)** — 한국에서 특히 다리 길이 선호. 크로치 높이/신장 ↑, 무릎 아래 길게.
3. **잘록한 허리 + 완만한 힙 (아워글래스)** — 저체중이라 볼륨은 절제, 허리 대비 대비만 강조.

## 2. 얼굴 (Face) — 한국 미인 기준

### 2-1. 형태
- **작은 얼굴 (소안)** — 절대 크기보다 "몸 대비 작게". → 모델링: 머리 스케일 축소.
- **V라인 턱** — 갸름한 턱선이 뾰족한 턱끝으로 수렴. 정면 V자, 하관 좁힘 + 턱끝 전진.
- **둥근 이마** — 완만하게 볼록한 이마.

### 2-2. 이목구비 (텍스처가 담당하되 배치 기준)
- **눈**: 크고 둥글게 + 쌍꺼풀 + 애교살(하안검). 얼굴에서 비중 큼.
- **코**: 높은 콧대, 오똑.
- **입술**: 작되 **아랫입술 > 윗입술** (골든 립 비율).
- **피부**: 글래스 스킨(투명·윤기).

### 2-3. 비례 규칙 (모델링 배치 기준)
- **얼굴 3분할(수직)**: 헤어라인→눈썹 / 눈썹→코끝 / 코끝→턱끝 각 ≈ 1/3 (균등).
- **얼굴 5분할(수평)**: 눈 하나 폭 = 얼굴폭의 1/5, 눈사이도 눈 하나 폭.
- **세로:가로 ≈ 1.6:1** (긴 얼굴형이 이상).
- 아름다운 얼굴 = 3분할·5분할이 **균등**하고 전체가 작음.

## 3. 3D 모델링 적용 전략

### 3-1. 비율 변환 (H = 신장, 미터)
| 파트 | 근거 | 파라미터 (H 비율) |
|---|---|---|
| 머리 길이 | 7.6등신 목표(소두 착시) | 머리높이 ≈ H/7.6 ≈ 0.132H → 구 반경 **0.060H** (기존 0.072H서 축소) |
| 머리 중심 z | headtop ≈ H | headc ≈ 0.930H |
| 크로치(다리 시작) | 긴 다리 | pelvis z ≈ 0.55H 유지, 발목 낮춰 다리 최대화 |
| 어깨 폭 | 좁고 완만 | 반폭 ≈ 0.10H, 슬로프 |
| 가슴둘레 | 저체중·절제 | chest rx 0.078H, 버스트 구 소형 |
| **허리** | 아워글래스 강조 | waist rx **0.050H** (기존 0.058서 축소) |
| 엉덩이 | 완만 | pelvis rx 0.084H |
| 팔/다리 | BMI17 슬림 | 상완 0.030H·허벅지 0.055H (기존서 −10%) |
| 얼굴 | V라인 | 하관 x −38% 테이퍼 + 턱끝 −Y 전진 |

### 3-2. 얼굴 텍스처 매핑 (3분할 기준)
- 헤드 로컬 Z[0,1] → 이미지 V에 **3분할 균등** 정렬(눈=상1/3~중, 코=중, 입=하1/3, 턱끝=바닥).
- 가로는 5분할 중앙 3/5(눈~눈)가 헤드 정면에 오도록 U 스케일 조정.
- 정면 투영 한계 → 3⁄4각 마스크화. **정면 앨범 컷 우선**, 각도 컷 필요 시 스컬프트/UV 또는 Hyper3D Rodin 경로.

### 3-3. 단계 적용 순서 (이미 구축된 v2 파이프라인에 반영)
1. `_skin_body` 반경/z 랜드마크를 위 표로 교체 (소두·잘록허리·슬림사지·긴다리).
2. `build_head`/`hair_scalp`/`mat_face_v2` 머리 반경 0.060H 동기화 + 얼굴 3분할 매핑 재튜닝.
3. 버스트 구 소형화(저체중 절제).
4. 멤버별 신장만 차등(개인차), 비율 규칙은 공통.
5. 정면·측면·34 검증 렌더 → 앨범 컷 확정.

### 3-4. 한계 & 다음 경로
- 절차적 프리미티브는 "실루엣·비율" 재현엔 유효하나 **표면 해부(쇄골·무릎·발 디테일)**엔 한계.
- 포토리얼 필요 시: ① 스컬프팅 + UV 언랩(멀티앵글 텍스처), ② **Hyper3D Rodin**(턴어라운드→메시 자동생성) 교체.
