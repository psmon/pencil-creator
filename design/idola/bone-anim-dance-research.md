## 2. 연구용 데이터셋 (SMPL — 클립 아닌 "생성/학습"용)

- **AIST++** — 최대 규모 3D 댄스(1,408 시퀀스, 30인, **10장르**, SMPL 60fps, 18k초). 벤치마크·**음악→댄스 AI 생성**(FACT). 상용은 라이선스 확인 필요. SMPL→BVH 변환 필요.
- **FineDance / DiffDance / ChoreoMuse / Robust Dancer** — 음악 조건부 3D 댄스 생성 논문. "곡에 맞춰 안무를 생성"하는 방향(우리의 비트 그리드 접근의 상위호환). 코드/모델 공개 다수.
- 시사점: **AIST++류는 "곡→안무 자동생성"**, CMU/Bandai/Mixamo류는 **"기성 댄스 클립을 리타겟"**. 우리는 후자(클립 리타겟)가 즉시 실용적.

## 3. 우리 리그로 리타겟 (핵심 통합 경로)

우리 리그 = **커스텀 17본** + **다리 IK**. mocap은 보통 풀바디 FK 휴머노이드.

### 리타겟 도구
- **Rokoko Studio Live (Blender 무료 애드온)** — 소스/타깃 아마추어 지정 → Build Bone List → 본 매핑 → Retarget. Mixamo/UE 프리셋 내장. 하드웨어 없이 리타겟만 사용 가능.
- Auto-Rig Pro Remap(유료), Mixaify(→Rigify), CGDive Mixamo 애드온.
- **네이티브(애드온 無)**: BVH/FBX 임포트 + **Copy Rotation 컨스트레인트**로 본별 회전 복사. 우리는 두 스켈레톤을 다 알므로 **매핑을 스크립트로 직접 구현 가능**(헤드리스 파이프라인에 적합).

### 우리 리그 특이사항 처리
1. **본 이름 표준적** (`hips/spine/chest/neck/head/upperarm.L/R/forearm/hand/thigh/shin/foot`) → mocap 관절과 1:1 매핑 쉬움.
2. **다리 IK 충돌**: mocap은 FK 다리 회전을 줌. 두 선택지 —
   - (A) mocap 재생 동안 **다리 IK 끄고 FK로** thigh/shin/foot 직접 구동 (간단).
   - (B) mocap **발목 월드좌표를 우리 FootIK 타깃에 베이크** → 발고정 유지(우리 자연걸음 로직과 호환). 무릎 폴 각도(+90) 유지.
3. **팔**: 현재 정지 → mocap이 팔을 구동(원하는 댄스). 손가락은 스텁/장갑이라 **손가락 채널 무시**(나중).
4. **비트 정합**: 클립을 BPM 84.2로 **타임스케일**, 프레이즈 경계 컷, **NLA**로 멤버별 위상 오프셋·블렌드·루프. 스포트라이트 구간엔 강조 클립.
5. **스케일**: 리그 신장 1.68m에 맞춰 오토스케일/루트모션 정합.

## 4. "본 애니 댄스기법" 요약
- mocap = **본별 회전(+루트 이동)** 시퀀스. 리타겟 = 소스 본 회전을 타깃 본에 (레스트포즈 차이 보정하며) 복사.
- **NLA(비선형 애니)**: 클립을 스트립으로 쌓아 **블렌드/루프/가법 레이어/시퀀싱** → 안무 구성. 우리 절차적 그루브를 **가법 레이어**로 얹어 개성 부여 가능.
- 발고정(풋락)·무릎 폴·팔 관통 방지 등 **우리가 이미 해결한 제약**은 리타겟 결과에도 그대로 적용(무릎 폴 +90 유지).

## 5. 추천 파일럿 (헤드리스 자동화 적합순)
1. **Bandai Namco / CMU BVH** 한 개(잔잔한 sway·아이돌 포인트류)를 **스크립트로 다운** → Blender 임포트 → **스크립트 본매핑(Copy Rotation)**으로 `Rig_u`에 리타겟 → 검증. (애드온·로그인 불필요, 재현 가능)
2. 좋으면 4인에 확장 + NLA로 위상 오프셋 + 비트 타임스케일. 스포트라이트 구간만 강조 클립 교체.
3. K-pop 톤이 꼭 필요하면 **Mixamo/XSTAGE**(사용자가 수동 다운로드) 클립을 같은 파이프라인에 투입.

### 라이선스 주의
상용 아이돌 산출물이면: CMU(원본 재판매 금지), Mixamo(원본 재배포 금지·프로젝트 사용 OK), AIST++(연구 라이선스—상용 확인), XSTAGE(무료분 약관 확인). **리타겟 결과(우리 캐릭터 애니)는 대개 사용 가능하나 원본 클립 재배포는 금지**가 공통.
